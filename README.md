# Vivek Sagarwal — Developer Portfolio

A static personal developer portfolio deployed with GitHub Pages.

## Live site

https://sagarwal-bit.github.io/vivek-portfolio/

## Development and deployment

The production site is the root `index.html` and requires no framework build step. GitHub Actions copies only the production HTML, favicon, and resume PDF to the Pages artifact on every push to `main`.

The legacy React source retained in this repository is not part of the deployed portfolio artifact.
